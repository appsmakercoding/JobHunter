# Job Hunter 💼 (v3.0)

বাংলাদেশের স্টুডেন্ট ও চাকরিপ্রার্থীদের জন্য অল-ইন-ওয়ান অ্যাপ। **Powered by Hasan**

## APK বানানোর নিয়ম (ফোন থেকেই)
1. এই জিপের **সব ফাইল** GitHub repo-তে আপলোড করুন (`.github` ফোল্ডার ও `signing` ফোল্ডারসহ)। repo অবশ্যই **Public** হতে হবে।
2. repo-র **Actions** ট্যাব → **Build Job Hunter APK** → **Run workflow**।
3. ৫–১০ মিনিট পর repo-র **Releases → Job Hunter — Build #N → Assets → JobHunter-release.apk** থেকে সরাসরি ডাউনলোড করে ইনস্টল করুন। (Artifacts-এও থাকে।)
4. **Actions → Update Jobs → Run workflow** একবার চালিয়ে নিন, তাহলে সাথে সাথে চাকরির তালিকা ভরবে। এরপর প্রতি ৬ ঘণ্টায় নিজে আপডেট হয়।

> নতুন APK আগেরটির ওপর আপডেট হিসেবে বসে (একই signing key + বাড়তি versionCode), পুরনো অ্যাপ মুছতে হবে না।
> নিজের গোপন key চাইলে repo Settings → Secrets-এ `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS` দিন।

## ফোল্ডার
- `www/` — অ্যাপের কোড, `resources/icon.png` — আইকন
- `.github/workflows/build-apk.yml` — APK বিল্ড
- `.github/workflows/update-jobs.yml` — চাকরি আপডেট
- `scripts/fetch-jobs.mjs` — চাকরি সংগ্রহের স্ক্রিপ্ট, `data/` — jobs.json ও curated.json

## নিজের বাংলাদেশি সার্কুলার যোগ
GitHub-এ `data/curated.json` এডিট করুন:
```json
[{"title":"সহকারী শিক্ষক","org":"DPE","loc":"সারা দেশ","deadline":"2026-12-30","date":"2026-11-10","url":"https://...","tags":["সরকারি"],"cat":"govt"}]
```
Commit করলেই Update Jobs চলে। `cat` হতে পারে: govt, bank, ngo, edu, it।

## সংস্করণ ৩.১ — নতুন সেবা
ছবি ও স্বাক্ষর রিসাইজ (সরকারি আবেদনের মাপ/KB) · ছবি থেকে PDF · ইমেইল, LinkedIn ও WhatsApp মেসেজ টেমপ্লেট · শব্দভাণ্ডার ও কুইজ · স্টাডি টাইমার · ক্যারিয়ার রোডম্যাপ · ব্যাংকিং প্রশ্ন · অ্যাপের ভেতরে নতুন সংস্করণের নোটিশ।

## ডাউনলোড পেজ (বন্ধুদের লিংক দেওয়ার জন্য)
repo → **Settings → Pages → Branch: main, Folder: /docs → Save**। কিছুক্ষণ পর `https://আপনার-ইউজারনেম.github.io/রিপোর-নাম/` লিংকে সর্বশেষ APK-র ডাউনলোড বাটন আসবে। এই লিংক Facebook/WhatsApp-এ শেয়ার করুন।

## সংস্করণ ৩.২ — নতুন
- **পরীক্ষাভিত্তিক প্রশ্নব্যাংক:** মডেল টেস্টে BCS / প্রাথমিক শিক্ষক / ব্যাংক জব আলাদা করে বেছে অনুশীলন (মোট ২৭০+ প্রশ্ন)।
- **সিভিতে ছবি ক্রপ:** আঙুলে সরিয়ে ও জুম করে ছবি ঠিক করুন।
- **সিভিতে স্বাক্ষর:** আঙুলে আঁকুন অথবা কাগজে করা স্বাক্ষরের ছবি দিন (ব্যাকগ্রাউন্ড নিজে মুছে যায়)।

## সংস্করণ ৩.২
- **পরীক্ষাভিত্তিক প্রশ্নব্যাংক:** মডেল টেস্টে BCS / প্রাথমিক শিক্ষক / ব্যাংক জব বেছে সেই পরীক্ষার প্রশ্ন, মক ও ভুলের খাতা। (প্রশ্ন বাড়াতে `www/js/qbank.js`-এ `[বিষয়, প্রশ্ন, [৪টি অপশন], সঠিক উত্তরের ক্রম]` যোগ করুন)
- **সিভিতে ছবি ক্রপ:** আঙুলে সরিয়ে ও জুম করে মুখ ঠিক জায়গায় বসানো যায়।
- **সিভিতে স্বাক্ষর:** আঙুলে আঁকা বা কাগজের ছবি থেকে। ATS (আন্তর্জাতিক) টেমপ্লেটে ইচ্ছাকৃতভাবে স্বাক্ষর বসে না।
